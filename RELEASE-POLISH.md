# Presentation and mobile release pass

- **Fighter identity:** Each of the eight fighters gets a small visual silhouette adjustment, distinct idle lean and breathing amplitude. The heavyweight, evasive and rushdown characters read differently while retaining their existing artwork. Combat body dimensions and hitboxes are unchanged.
- **Hit reactions:** Body, low, heavy, uppercut, aerial and meteor hits receive different recoil directions and compression. Existing knockdown, throw, slow-motion KO and defeated-pose systems retain priority. Reactions use simulation time and respect reduced-motion settings.
- **Entrances:** First-round entrances open subway doors, climb from a rooftop/parking edge, step forward from Cleveland's crowd, or walk in from the street. Arrival settles before the round/fight countdown. These are cosmetic stage-specific arrivals rather than changes to fighter positions or attack ranges.
- **Finishing-exchange replay:** After the final slow-motion finish, finisher and victory pose, a short automatic replay plays before match highlights. It records up to 72 state snapshots at 12 Hz, keeps the last four seconds for playback, and interpolates positions. Rendering uses copies of fighters and a static cached backdrop; it never re-simulates combat or changes rewards. It is a visual replay, without recorded audio, projectiles or particle effects. Pause/background/settings gates and navigation cleanup protect the original match flow. CPU showcase waits for the replay before rotating bouts.
- **Android/mobile:** Auto resolution is capped at 1650 pixels on coarse-pointer devices; explicit 4K stays available. Two-entry stage-detail caches reduce retained canvases. Backgrounding clears transient stage caches and stale input/time accumulators. The Android WebView requests unbuffered touch dispatch and keeps the screen awake. Phone Check adds a 95th-percentile frame-time measurement and suggests lighter settings when needed.

Validation: `node release-polish.test.cjs`, movement/defeat regression tests, offline tests, browser CPU showcase simulation (nine rotating bouts with the replay enabled), and emulated 844 × 390 touch layout at 3× device scale. All 14 visible touch buttons fit horizontally; Auto chose 1650 pixels. The replay started only after final victory gates and left live combat state unchanged. Android build validation runs in CI. Physical Android/Xbox latency, thermal behavior and sustained frame rates still need device testing; no physical device was available during this pass.
